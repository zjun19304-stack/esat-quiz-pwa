ESAT 题库 — 使用说明
================================

【最简单的方式：直接打开网址】

    https://zjun19304-stack.github.io/esat-quiz-pwa/

用手机自带浏览器，或电脑上的 Chrome / Edge 打开就行。
首次打开会要求输入激活码，把卖家给你的那串码粘进去，点「激活」即可。

注意：
  - 请用系统浏览器打开，**不要在微信内置浏览器里打开**（部分功能会被限制）
  - 首次激活请保持联网，题库图片会在后台自动缓存，之后断网也能用
  - 476 张题目图片全部缓存完成后即可完全离线使用


【离线方式：本地运行】

如果需要完全不依赖网络（比如在学校机房、没有外网的环境），
可以把整个文件夹拷到本地，用「本地服务器」方式打开。

为什么不能直接双击 index.html？
浏览器的安全机制要求加密验证（激活码校验）和离线缓存（Service Worker）
只能在 https 或 http://localhost 环境下运行。直接双击 file:// 打开会导致：
  - 激活码无法验证
  - 离线缓存失效

Windows：
  1. 确保已安装 Node.js 或 Python（二选一，版本不限）
  2. 双击文件夹里的「启动.bat」，会自动打开 http://localhost:8000

macOS / Linux：
  打开终端，进入本文件夹，执行：
      python3 -m http.server 8000
  然后浏览器访问 http://localhost:8000
  （若装了 Node，也可执行：node serve.js）

手机 Android：
  电脑按上面方式启动后，手机连同一个 WiFi，
  浏览器访问 http://电脑局域网IP:8000（电脑 IP 类似 192.168.x.x，用 ipconfig 查）


【激活与授权】

- 首次打开输入激活码 → 点「激活」 → 自动解锁题库
- 激活码有有效期（通常为 90 或 180 天），过期后联系卖家获取新激活码，重新激活即可
- 激活状态保存在「这台设备的这个浏览器」里：
    换浏览器、清理浏览数据、换设备 → 都需要重新激活
- 激活成功后断网也能用；图片缓存未完成就断网的话，联网重新打开一次即可


【激活失败怎么办】

提示「当前环境不支持加密验证」
    → 直接双击了 html 文件（file://）。用网址打开，或按上面「离线方式」启动本地服务器。

提示「激活码格式错误」
    → 只复制了一半，丢了「.」后面的部分。重新完整复制，是一整行，「.」前后都要。

提示「激活码无效或已被篡改」
    → 复制时缺字符或多了空格。重新完整复制，不要带换行和空格。

提示「激活码已过期」
    → 超过有效期，联系卖家获取新激活码。

微信里打开白屏 / 图片不显示
    → 微信内置浏览器限制。点右上角「···」→「在浏览器中打开」。


【更新】

卖家发布新版本时，会提供新的离线包和新的激活码。
离线方式的用户覆盖解压即可；网址方式的用户刷新页面就能拿到最新版。


【隐私】

本应用不联网上传任何数据。激活码校验在你的设备上用内置公钥本地完成，
题库内容也只解密后保存在本机。
