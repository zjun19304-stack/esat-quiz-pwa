ESAT 题库离线版 — 使用说明
================================

【重要】必须通过"本地服务器"打开，不能直接双击 index.html！
原因：浏览器的安全机制要求加密验证功能（激活码校验 / Service Worker 离线缓存）
只能在 https 或 http://localhost 环境下运行。直接双击 file:// 打开会导致：
  - 激活码无法验证（提示"请通过本地服务器打开"）
  - 离线缓存失效，图片仍需联网
所以务必用下面的方式启动。


【电脑 Windows】
1. 确保已安装 Node.js 或 Python（二选一，版本不限）
2. 双击本文件夹里的"启动.bat"
   - 它会自动打开浏览器 http://localhost:8000
   - 若提示缺少 Node/Python，请先安装后再试
3. 出现激活界面后，输入卖家给的激活码，点击"激活"即可


【电脑 macOS / Linux】
打开终端，进入本文件夹，执行：
    python3 -m http.server 8000
然后浏览器访问 http://localhost:8000
（若装了 Node，也可执行：node serve.js）


【手机 Android】
方式一：用支持"本地服务器"的 App（如 Termux，安装 Python 后运行上面的命令）
方式二：电脑按上面启动后，手机连同一 WiFi，浏览器访问 http://电脑局域网IP:8000
         （电脑IP 类似 192.168.x.x，可在电脑"ipconfig"查到）
方式三：把整个文件夹上传到任意静态托管平台（如 EdgeOne Pages / 腾讯云开发 / Vercel）
         托管后通过 https 访问，功能完整


【激活与授权】
- 首次打开输入激活码 → 点"激活" → 自动解锁题库
- 激活码有有效期，过期后联系卖家获取新激活码，重新激活即可
- 激活成功后，453 张题目图片会在后台缓存，之后离线 / 断网也能秒开
- 保留"已有账号？登录"入口，供内部测试的学生密码登录使用


【更新】
卖家发布新版本时，会提供新的 zip + 新激活码。覆盖解压本文件夹即可。


【隐私】
本应用完全离线运行，激活仅在本地用内置公钥校验签名，不上传任何数据。
